## 2. 环境证据

### 2.1 硬件

```
$ lspci -nn | grep -E 'VGA|3D'
00:02.0 VGA compatible controller [0300]: Intel Corporation 4th Generation Core
       Processor Family Integrated Graphics Controller [8086:041e] (rev 06)
01:00.0 3D controller [0302]: NVIDIA Corporation GP104 [P104-100] [10de:1b87] (rev a1)
```

`8086:041e` 是 Intel HD 4400（Haswell 核显）。**硬件存在，但未被浏览器使用。**

### 2.2 系统 OpenGL

```
$ glxinfo -B
OpenGL vendor string: NVIDIA Corporation
OpenGL renderer string: NVIDIA P104-100/PCIe/SSE2
OpenGL core profile version string: 4.6.0 NVIDIA 580.178.04
```

桌面 OpenGL 上下文绑定在 NVIDIA 独显上。

### 2.3 浏览器实际渲染设备（T00 真正的判据）

在开发服务器页面内通过 `WEBGL_debug_renderer_info` 读取：

```js
const gl = canvas.getContext('webgl2');
const dbg = gl.getExtension('WEBGL_debug_renderer_info');
gl.getParameter(dbg.UNMASKED_RENDERER_WEBGL);
```

结果：

| 字段 | 值 |
|---|---|
| UNMASKED_RENDERER_WEBGL | `ANGLE (NVIDIA Corporation, NVIDIA P104-100/PCIe/SSE2, OpenGL 4.5.0)` |
| UNMASKED_VENDOR_WEBGL | `Google Inc. (NVIDIA Corporation)` |
| GL_VERSION | `WebGL 2.0 (OpenGL ES 3.0 Chromium)` |
| WebGL2 | 支持 |
| MAX_TEXTURE_SIZE | 32768 |
| devicePixelRatio | 2 |
| 视口 | 800×543 |
| UA | `Chrome/152.0.7977.130 Electron/44`（X11, Linux x86_64） |

**结论：游戏实际渲染在 NVIDIA P104-100 上，不是 HD 4400。**

> 注意 `MAX_TEXTURE_SIZE=32768` 与 P104-100 相符；HD 4400 的典型上限为 8192，
> 可作为将来复核集显是否真正生效的辅助信号，但不能单独作为判据。

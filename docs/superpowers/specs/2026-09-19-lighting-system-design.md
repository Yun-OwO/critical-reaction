# 光影系统设计

状态：待用户确认

## 目标

在不改变战斗规则的前提下，为 Phaser 4 游戏增加可分级的局部 Bloom、动态环境光和轻量阴影，并提供自动与手动质量设置。

## 质量模式

提供四种设置：

- 自动：根据 WebGL、触摸设备和运行状态选择低、中或高质量。
- 低：仅使用现有 ADD 混合、基础光晕和少量阴影；关闭高成本效果。
- 中：启用玩家、Boss、电子、冲刺和反应的多层光晕，使用轻量环境色调变化。
- 高：在中质量基础上增加更强光晕层、动态光照覆盖和更柔和阴影；仍不使用全世界高分辨率全屏 Bloom。

设置持久化到浏览器本地存储，启动时恢复上次选择。若浏览器不支持存储，退回自动模式，不影响游戏运行。

## 光影架构

新增视觉质量模块，集中管理质量模式、光晕层数、透明度、阴影开关、环境光强度和粒子上限。模块只提供纯数据和设备能力判断，不依赖 Phaser 场景。

GameScene 负责根据模块参数创建和更新：

- 玩家核心和轨道电子光晕。
- 普通敌人和 Boss 光晕。
- 冲刺残影与第二段冲刺爆发环。
- 反应、命中和死亡闪光。
- 对象下方的椭圆软阴影。

## Bloom 策略

默认采用多层半透明对象光晕与 ADD 混合，避免对 4800×2400 世界做全屏高分辨率模糊。高质量模式可以提高关键对象光晕层数和透明度，但设置亮度上限，避免过度曝光。

低质量模式只保留一层光晕；中质量保留两层；高质量保留三层。光晕对象在创建时复用，更新时只修改位置、缩放、透明度和颜色。

## 动态环境光

环境光根据模式、温度和 Boss 状态插值：

- 氧化态偏橙红。
- 还原态偏黄青。
- 高温向红色过渡并提高边界亮度。
- Boss 出场和阶段变化增加紫红色局部光。
- 酸池和撤离区保持低强度绿色或青色光。

通过半透明环境覆盖层和局部径向光晕实现，不引入逐像素光照依赖。

## 阴影策略

玩家、普通敌人和 Boss 使用可复用椭圆阴影。阴影大小按对象类型配置，冲刺期间短暂拉伸。低质量模式关闭普通敌人阴影，只保留玩家和 Boss 阴影。

## 手动设置界面

在 LabScene 增加视觉设置入口：

- `自动`：推荐默认值。
- `低质量`：适合低端设备和移动设备。
- `中质量`：默认桌面体验。
- `高质量`：完整局部光影表现。

当前选择显示在界面中，按左右方向键或点击按钮切换，Enter 继续进入游戏。设置变化立即更新共享视觉质量配置，下一次进入 GameScene 时按新配置创建效果。

## 性能与兼容性

- 继续支持 WebGL 和 Canvas 回退。
- Canvas 回退自动限制为低质量效果。
- 移动设备默认不超过中质量。
- 限制同时存在的光晕、阴影和粒子数量。
- 不在每帧创建销毁光影对象。
- 保留现有轨道段数和粒子数量降级策略。

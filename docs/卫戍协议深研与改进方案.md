## 一、修正联机选型：两层权威 > 宿主权威状态同步

### 之前的选择（基于 geometry-duel 研究）
宿主权威 + 状态同步：host 跑全量模拟，guest 上报输入、收 30Hz 快照、本地插值。

### 卫戍协议的答案：**分层权威**（`Match.js:61-76`）
- **元游戏层（房间/商店/背包/结算）服务器权威**：所有操作意图由服务端校验执行，客户端只收视图。
- **战斗层：可信客户端权威**——服务器把一场战斗压成**确定性 JSON Spec**（种子+初始状态）下发，
  权威客户端用**与服务器同构的确定性模拟器**在本地跑，只上行：
  - `b.progress` 心跳（≈1Hz）
  - `b.result` 终局战报（体积受限、字段白名单校验）
- **带宽≈0**。观战 = 把同一份 spec 发给观看者，从 `elapsed` 快进本地复演。
  服务器"永不上报 display replicas"。

### 为什么这对临界反应是对的
搜打撤的每场战斗本来就只属于该玩家——快照同步在传大量"只有一个人关心的状态"。
分层权威下：**大厅/房间/撤离结算跑在主机手机的服务器上，各人的战斗本地模拟、只交战报**。

### 确定性六件套（卫戍协议的实现清单，`sim/rng.js`、`sim/spec.js`、`sim/Battle.js`）
1. 单一 PRNG：mulberry32 种子化，"The ONLY source of randomness in the sim"；
2. 无 wall clock、无 Math.random（"same spec + same data = same result on every machine"）；
3. 固定 tick 1/30s，长局用 `tickCount*dt` 累计避免浮点漂移；
4. Spec JSON 往返安全（Infinity→±1e308、NaN→null）；
5. 可注入时间源（RealScheduler/VirtualScheduler）——整场对局毫秒级跑完，用于测试/校验/回放；
6. **同一份模拟代码两端跑**：sim 以只读 ES Module 经 HTTP 提供给浏览器。

### 防作弊（信任但验证，成本极低）
- 结果合理界校验（击杀≤出怪总量、掉落≤上界），**按白名单字段重建战报，从不原样信任**；
- `SP_VERIFY=sample`：约 1/8 战报抽样重模拟，不一致以服务器为准；
- 权威客户端掉线/超时 → 服务器从 spec 重跑接管（`Match.js:66-67`）。

## 二、联机工程全家桶（可近乎原样移植）

### 部署形态：手机即服务器
- LAN 联机 = 主机玩家的手机跑 Node 服务端，绑 `0.0.0.0` + 临时端口，队友浏览器直连（`main.js:11-13`）；
- 公网 = `cloudflared tunnel`（`index.js:647`）；
- **启动自检三件套**（解决 WebView 竞态 + Android 低端口限制）：`--port 0` → HTTP `/healthz` ✓ →
  真实 WebSocket upgrade `/ws` ✓ → **握手文件 tmp+rename 原子写**，Activity 轮询拿地址再加载 WebView。

### 传输与协议（`net.js`、`shared/protocol.js`）
- WebSocket + JSON 文本帧，`{t, rid}` 帧格式（rid 回显做请求关联）；
- **一份 protocol.js 双端共用**：客户端发送前先本地 validate，服务端同一张表做校验；
- token-bucket 40 msg/s + 重发型意图第二桶（2/s burst 6）双限流；
- 背压分级：发送队列 >1MB 丢可丢帧（只有战斗快照），>16MB 断线等全量重同步；
- 协议版本号独立于应用版本，hello 不匹配即拒。

### 断线重连全家桶（`net.js:124-211`、`lobby.js`、`Match.js:44-47`）——联机 UX 最大的"高级感"来源
1. 128-bit 重连 token，断线会话保留 10 分钟（solo 单人局 24h）；
2. 重连 = 带 token 的 hello → 服务端换绑 socket → **全量重同步**（重发视图 + 在打战斗的 spec+elapsed 快进续上）；
3. 重复 hello 节流合并（1s 窗口），防重连风暴放大；
4. 大厅掉线 60s 宽限释放座位；对局中掉线保留座位、阵容继续自动作战；
5. 掉线托管：仅玩家显式开过的 AI 才替他操作；draft/准备超时自动解决；
6. host 迁移：最低座位已连接人类接任；
7. 对局进行中**不支持中途加入**（房间制熟人局的合理取舍，明确写进设计）；
8. 客户端侧：指数退避（500ms×2 上限 10s ±20% jitter）、"最旧未答 ping"15s 判死（防后台节流误判）、
   服务器时钟偏移估计、BroadcastChannel 多标签页身份仲裁、visibilitychange 立即重连。

### 联机 UX 规范（`docs/research/06-multiplayer-ux.md` + `09-ux-official.md`）
- 阶段倒计时全部服务端权威，客户端只渲染 deadline；一切超时都有自动策略兜底；
- 交流只有表情（36 官方表情，1s CD），无文字聊天；服务器广播 ticker 播报大事；
- 等待态胶囊："⌛ 作战结束，等待队友完成作战" + 队友 ✓/••• 状态点；
- 淘汰者弹"继续观战/退出"；对局进行中 join 直接拒绝。

## 三、玩法与数据表设计（data/ + docs/research/）

### 最值得抄的机制（按价值排序）
1. **层系统 + 线性公式 + 里程碑**（bonds）：成长值 L 全局持久、效果 = a + b·L、每 N 层触发掉落——
   临界反应的"反应进度/催化层数"可直接套用为贯穿局内的滚雪球轴；
2. **反失控双闸**（`11-limits-official.md`）：硬上限（999 层封顶）+ **伤害取消而非截断**（单发≥30万直接归零）——
   数值崩坏的头号解法，且"超额即归零"与临界反应的"临界/失控"主题天然契合，可直接戏剧化；
3. **占位符波次 + 战力等价替换**（`08-waves-official.md`）：波次表只写抽象模板（N/E/S+飞行变体），
   运行时按战力公式 BE=(hp+5atk+3def+3res)/系数 做到"换怪不换难度"，刷新窗口守恒；
4. **每模式一张完整参数单**（config.json）：回合参数/敌人曲线/限时/商店/禁用全内聚，调参不动代码；
5. **最小覆写层**（tuning.json）：生成数据为主、覆写条目必须带 `_why`、过时旋钮坚决删——数值只留一个真相源；
6. **每局随机禁用**：抽 N 条羁绊 → 派生禁用名单，强制每局换 build、防背版；
7. **由构筑深度解锁的隐藏关**（层总和>350/1200 进 R15）——搜打撤的撤退结算可挂同类门槛解锁高收益支线；
8. **档案化敌人类型系统**（factions.json）：危害类型分池 + 半期自动升级为强化版。

### 设计方法论（docs/research/ 本身是模板）
- **置信度标签**：`[DATA]/[VERIFIED]/[WIKI]/[COMM]/[INFER]/[ASSUMED]`——每条数值都能回答"它凭什么"；
- **文档-JSON 孪生**：md 给人读、同名 JSON 给代码吃，00-INDEX 标出"关键机器路径"；
- **显式裁决表**：矛盾发现与裁决 §7、未决问题+推荐默认值 §8，分歧永不悬置；
- **文档承认错误并闭环**：08 文档开头声明"取代 05 §3.2"，随后从数据里删掉全部被证伪的自调旋钮。

## 四、客户端架构与美术/UX

### 客户端分层（public/js/）
- **UI 层 = DOM（Preact）**，战场层 = Pixi，3D 棋盘 = three 垫底、一个相机驱动两层；
- **store.js：70 行 observable store**（get/set/patch/subscribe）+ `useStore(selector)`；
  路由是从 store 派生的纯函数；"UI 永不本地改对局状态，只重渲染服务端推送"（`screens/game.js:31`）；
- 战斗 runner 在**后台标签页用 250ms interval 泵 + 有界快进**兜底；丢失的战报重连后补报。

### 美术"高级感"手法（theme.css / components.css，零运行时成本）
1. **token 体系**：五级近黑表面 + 单主色多阶（含 rgba 变体）+ 语义色；
   动效统一 `cubic-bezier(.2,.8,.2,1)` + 150/200/250ms 三档；
2. **rem=100 设计像素等比缩放**（`clamp(40px, min(100vw/19.2, 100svh/10.8), 240px)`）——
   全部 UI 按设计像素书写，天然等比适配且规避 CJK 最小字号钳制（比我们的 s 因子更优雅）；
3. **括号框角**：四角 L 形描边（8 条 linear-gradient），hover 时括号角 scale(1.04) 淡入——签名元素；
4. **三层静态氛围背景**：radial 光晕 + masked 测绘网格 + 扫描线/暗角/feTurbulence 颗粒；
5. **材质细节**：主按钮 -55° 斜纹 hatch + 顶部高光；三层 box-shadow 面板 glow；
   clip-path 六边形/八边形芯片；发光状态点三态；
6. **动效纪律**：屏幕切换只做 opacity；连接横幅**延迟 0.6s 才出现**（防闪烁）；
   按钮 busy 用底边细扫条不用 spinner；同文案 toast 合并 ×N；`prefers-reduced-motion` 全局降级。

### 音频管理（audio.js，671 行）
- 手势解锁的 iOS 全套特判（statechange 重新武装、1 采样 prime）；
- BGM intro→loop 交叉淡化 + **BGM 完全由状态派生**（`bgmKeyFor(route, phase)` 纯函数，无人为切歌调用点）；
- SfxLimiter 四重节流（总并发 8 / 单位冷却 160ms / 同 URL 最小间隔 45ms / 叠音上限 2）；
- AudioBuffer LRU 且永不驱逐正在播的 BGM；整模块 never throws。

## 五、临界反应实施路线（修订版）

### P0 架构治理（不变，联机必要前置）
维持《改进方案-基于参考项目研究.md》的 9 步拆分，但第 8 步升级为：
**core/RunProfile + 确定性 RunSim**——把战斗循环（敌人 AI/弹幕/命中判定）重构为
「spec 驱动、单 PRNG、固定 tick、无 wall clock」的确定性模拟。这是分层权威联机的地基。

### P1 联机路线（修订：三层权威）
| 阶段 | 内容 | 参照 |
|---|---|---|
| M1 传输壳 | Capacitor 侧跑局域网房间服务器（Java WebSocket 或 Node sidecar），或 WebRTC 星型；房间码+lobby 协议照抄 shared/protocol.js 模式 | 卫戍协议 lobby.js |
| M2 元层权威 | 房间/背包/撤离结算服务端校验；`{t,rid}` 协议 + 双端共用 schema + token 会话 + 重连全量重同步 | net.js/SessionRegistry |
| M3 战斗可信客户端 | RunSim 确定性化（PRNG/tick/spec）→ spec 下发 → 本地跑 → 心跳+战报上行 → 白名单校验+抽样重模拟 | Match.js/sim/ |
| M4 联机 UX | 断线重连全家桶、等待胶囊、表情-only 交流、掉线托管、host 迁移 | 06-multiplayer-ux.md |

部署形态决策点： Capacitor + Java 嵌入式服务器（NanoHTTPD/WebSocket 库，改动小） vs
迁移 nodejs-mobile（手机即服务器 + 同构 sim 两端跑，与卫戍协议同款但壳要换）。倾向：先 M1 用 Java 壳验证玩法，M3 若确定性 sim 落地后再评估 nodejs-mobile。

### P2 内容与体验
- 数据表治理：引入"模式参数单 + 最小覆写层（带 _why）+ 占位符波次"三件套；
- 机制：反应层数成长轴（层系统）、**失控伤害取消**（戏剧化为临界反应主题规则）、
  每局随机禁用祝福、构筑深度解锁隐藏支线、占位符波次等价替换；
- 美术：theme token 体系整体移植（含 rem 设计像素缩放替换现有 s 因子）、括号框角、
  三层氛围背景、动效三档纪律；
- 音频：BGM 状态派生选曲 + SfxLimiter 四重节流 + LRU（在 BgmManager 之上套这层）；
- 联机 UX：全部照抄 09-ux 规范。

### 明确不做
- lockstep 帧同步（geometry-duel 反例：假确定性）
- 全量宿主权威状态同步（被分层权威取代：带宽大且没必要）
- 公网陌生匹配的防滥用矩阵（只做 LAN/私房熟人局，保留 token bucket 即可）

## v0.2.3 实施进展（2026-10-07 更新）

### 已落地

- **护盾改革**（基础上限 10、衰减 4/s、重复获取减半）
- **祝福再平衡**：电子类折算为压制概率 0.35/颗，全局压制软上限 2.2，觉醒「催化威能」+15%
- **单次攻击最多破一层**（溢出伤害不顺延到下一层）
- **进化系统**（借鉴 colorist 染料喂养：局内染料房 → 等级 → 克制伤害 +6%/级、全局 +1%/级）
- **自适应难度**：温度随通关推进速度上升（快推 18°/房、慢推 4°/房），与"分层权威"思路同源：让系统响应玩家行为而非固定曲线
- **开发者选项**：调试叠层（chemic 式双路 FPS + 地图种子）、碰撞箱显示（Phaser 内建 `world.drawDebug` + 按需 `createDebugGraphic()`）
- **体积化群系地形** + 碰撞体积与死路防护（见 `src/game/world/biomes.ts`）

### 关键认知（补充原方案）

- **Loader 泵依赖 RAF**：页面被系统节流（隐藏窗口/后台标签）时 RAF 停摆 → 队列卡 `POPULATED` → 黑屏。已加 300ms 手动泵 + 12s `loadComplete()` 兜底（**"游戏永不阻塞于资源"**原则，与原方案 07-assets「游戏必须永不阻塞于 Spine」一致）

### 联机（未开始，规划不变）

仍是 **分层权威 + 确定性 Spec 下发**：元层服务器权威，战斗层可信客户端本地模拟，只上行心跳+战报，带宽≈0。前置工程是 GameScene 拆分（SpawnDirector / CombatResolver 抽离）+ 战斗循环确定性化（单 PRNG、固定 tick、无 wall clock、spec JSON 往返安全）。

## 4. 转换参数留档

```bash
# 何忆卫 → 项目格式
ffmpeg -y -v error -i <src>.mp3 -ac 1 -ar 22050 -c:a pcm_s16le assets/audio/<name>.wav
```

- 单声道 22050Hz：P0 快速导入的折衷，**不等于最终规格**
- 计划 §5.4 要求：保留立体声与高频的素材不应降采样；有明确收益才降
- P3 重新评估：刀刃/电弧的高频与空间线索可能被 22.05kHz 截断
